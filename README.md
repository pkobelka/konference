# Konference VHOS

Aplikace pro organizaci konference VHOS – kdo jede, kde spí, jakou má večeři, a kontrola, aby nikomu nic nechybělo ani nebylo zajištěno navíc.

- `index.html` – aplikace pro pořadatele (přihlášení e-mailem, stejný seznam jako Florián / Volby)
- `prihlaska/` – formulář pro partnery, každá firma má vlastní tajný odkaz `prihlaska/?k=…`

Běží na GitHub Pages: https://pkobelka.github.io/konference/

**Data nejsou v repozitáři** – jsou ve Firebase (projekt moje-budky) v uzlech
`konference2027`, `konference2027_prihlasky` a `konference2027_verejne`, chráněných pravidly databáze.
